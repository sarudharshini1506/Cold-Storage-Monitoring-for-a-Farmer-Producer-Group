# ❄️ Cold Storage Monitoring System

## Problem Statement

Farmer Producer Groups store perishable products in cold storage chambers. If the cooling system fails due to a power outage or equipment fault, the temperature rises unnoticed and the stored produce may spoil before anyone discovers the problem.

This project continuously monitors the chamber temperature, raises an alarm whenever the temperature exceeds the safe limit, and maintains a history of all readings for future analysis.

---

# Features

- Live temperature monitoring
- Search chamber records
- Filter by alarm status
- Temperature chart
- Dashboard summary
- Alarm detection
- REST API
- ESP32 (Wokwi) simulation
- JSON data storage
